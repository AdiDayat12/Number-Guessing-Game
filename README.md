# 🎯 Guessing Number Game

A simple and fun console-based number guessing game with three difficulty levels.

## 📋 Features

- Random number is generated each round
- 3 difficulty levels:
    - 🟢 Easy → 10 chances
    - 🟡 Medium → 5 chances
    - 🔴 Hard → 3 chances
- Hints are provided after each guess (e.g., "Too high" / "Too low")
- Automatically asks player if they want to play again after win or lose

## 🚀 How to Play

1. Choose a difficulty level.
2. Try to guess the correct number within the allowed number of attempts.
3. The system will tell you if your guess is too high or too low.
4. Win by guessing correctly before your chances run out.
5. At the end of the round, you can choose to play again or exit.
